# Security Policy

## Scope

DETA collects public historical market data. Do not submit exchange credentials, API secrets, wallet secrets, access tokens, or private account data in issues or logs.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, open a minimal issue asking for a private contact channel without including exploit details or secrets.

## Data integrity reports

For archive integrity, parsing, or checkpoint issues, include the affected exchange, market category, dataset type, symbol, date range, command, and sanitized error output. Never claim historical completeness based only on a successful command or unit tests.
